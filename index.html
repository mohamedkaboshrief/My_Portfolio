Car Price Prediction — Technical Breakdown

Dataset & Problem Framing

Trained on the Kaggle Car Price Prediction Challenge dataset. The goal is to accurately forecast pre-owned automobile transaction prices using multi-dimensional technical attributes including manufacturer, model, year, mileage, engine volume, gearbox, and drive wheels.

Data Cleaning & Feature Engineering Pipeline

  • Missing-Value Imputation: Systematic analysis of missing attributes; median/mode imputation based on vehicle segment distributions.
  • Duplicate & Outlier Handling: Detected and removed duplicated rows; bounded extreme target values using interquartile range (IQR) thresholds.
  • High-Cardinality Target Encoding: Evaluated the "Car" manufacturer/model feature (hundreds of distinct categories). Applied Target Encoding with smoothing to prevent data leakage and dimensionality explosion compared to standard One-Hot Encoding.
  • Feature Scaling: Applied normalization/standardization to numeric features across all baseline distance-based and linear models.

Algorithm Comparison (8 Models Tested)

Model Algorithm Category Status / Notes
Linear Regression Linear Baseline Baseline comparison; underfitted complex interactions
Lasso Regression (L1) Regularized Linear Performed feature sparsity testing
Ridge Regression (L2) Regularized Linear Reduced multicollinearity among correlated specs
K-Nearest Neighbors (KNN) Instance-based High inference latency on large feature space
Support Vector Regressor (SVR) Kernel Method Sensitive to high variance in vehicle price scale
Decision Tree Regressor Tree-based Prone to overfitting on training split
Gradient Boosting Regressor Ensemble Boosting Strong predictive power across dense clusters
Random Forest Regressor ★ Ensemble Bagging Selected Best Model — Optimal bias-variance balance
